Category 02

IVR Scraper & Audit Dashboard

Automated scraping of university IVR phone systems — mapping branch trees, calculating friction scores, and surfacing insights.

Process Pipeline
1

IVR Discovery

Identify universities with active IVR phone systems and catalog their main line numbers.

2

Branch Scraping

Navigate each IVR tree — Press 1, 2, 3… Map all sub-branches and record every possible path.

3

Friction Scoring

Score each system on call friction — branches, wait times, dead ends, and human reachability.

4

Audit Dashboard

Interactive dashboard comparing friction scores across universities with drill-down views.

How It Works

Many universities still rely on IVR (Interactive Voice Response) systems that create frustrating caller experiences. This project automates the entire auditing process — calling, navigating branches, mapping tree structures, and scoring the caller experience.

The friction score methodology accounts for tree depth, dead-end branches, time-to-human, and redundant menu options. Results are aggregated into an interactive audit dashboard.
